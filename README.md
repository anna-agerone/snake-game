# 🐍 snake.

A tiny Snake game in one HTML file. Arrow keys (or WASD) to move, Space to pause. Eat, grow, don't bite your own tail.

## 🚀 How this got here

This game was built with **one simple AI prompt** and deployed entirely by a **coding agent** — no manual `git push`, no human in the terminal. The whole point was just to confirm the deployment pipeline works. It does. 🎉

Think about that: one sentence to the AI, and here we are — a playable game, live on the internet. That's the power of working *with* AI instead of against it.

## 🧠 A quick nudge

If you've been nervous about AI, don't be. It's a tool, not a threat.

- Ask it to explain *why*, not just hand you *what*.
- Watch it do the boring parts, then try them yourself.
- Use it to move faster, not to think less.

You're not being replaced — you're being amplified. So go build something fun and let the robot ship it. 🚀
